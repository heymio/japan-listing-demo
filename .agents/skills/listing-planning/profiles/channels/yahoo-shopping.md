# Yahoo! Shopping planning profile

## Use when

Select this profile for a Yahoo! Shopping product page, store-controlled page, or campaign content area.

## Verify before planning

Confirm from the current store account, official guidance, and current live-page evidence:

- editable product information, media, specifications, options, descriptions, store and campaign areas;
- template/feed/integration/image constraints;
- merchant-controlled versus platform-controlled content;
- publishing and policy requirements;
- mobile/app-web behavior.

Do not assume a fixed page structure from an old capture or another merchant.

## Frontend reference intake

Ask for a preferred current Reference URL / product page / store page / screenshot set. Use a valid supplied page as the candidate **Primary Reference**; otherwise inspect 1–3 comparable current pages and recommend one.

Keep **Platform Capability evidence** separate from **Frontend Visual evidence**. Official rules do not substitute for current frontend visual proof.

Capture material shell, section order, option behavior, merchant/platform ownership and mobile/app-web behavior in the Channel Frontend Reference Pack. Final native-fidelity enforcement belongs to Hardening.

## Content roles

| Area | Planning role |
|---|---|
| Product identity | Product and offer recognition |
| Merchant-controlled media | Fast visual persuasion and proof |
| Description/enhanced area | Mechanism, use context, evidence and conditions |
| Structured attributes | Factual verification/filtering |
| Options/variations | Validated offer selection |
| Store/campaign area | Portfolio, promotion and routing when confirmed |

## Planning rules

Create the editable-slot map from current store/account evidence and live-page structure. Mark unavailable or uncertain fields `UNKNOWN` or `PENDING`.

Separate evergreen product content from volatile price, inventory, coupon and campaign content.

Define mobile-safe image crops, text density, option flows and long-form reading order before Production.

## Planning outputs

Record store/page target, editable fields and ownership, template/integration constraints, Primary Reference, Channel Frontend Reference Pack, evergreen/commercial-content split, mobile implications, page architecture and Complete Demo-Required Production Set.
