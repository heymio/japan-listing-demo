# Rakuten planning profile

## Use when

Select this profile for a Rakuten product page, store page, campaign page, or merchant-controlled content area.

## Verify before planning

Confirm from the current merchant account, store setup, official guidance, and live page evidence:

- editable product, image, video, specification, option, store and campaign areas;
- current builder/template/HTML/image/mobile constraints;
- merchant-controlled versus platform-controlled regions;
- publishing, approval and policy requirements;
- whether the target is a product page, store landing page, campaign page, or a combination.

Do not import module names, limits or ownership assumptions from another marketplace.

## Frontend reference intake

For a channel-native review target, ask for a current Rakuten Reference URL / store page / product page / screenshot set. Use a valid supplied page as the candidate **Primary Reference**; otherwise inspect 1–3 current comparable pages and recommend one.

Keep **Platform Capability evidence** separate from **Frontend Visual evidence**. Official rules do not substitute for current consumer-facing visual evidence.

Planning captures material shell, store/product navigation, brand-controlled content placement, section order and mobile behavior, and records them in the Channel Frontend Reference Pack. Final fidelity enforcement belongs to Hardening.

## Content roles

| Area | Planning role |
|---|---|
| Product identity | Product and offer recognition |
| Merchant-controlled media/content | Message sequence, mechanism, proof and use context |
| Specifications/options | Structured facts and offer selection |
| Store navigation | Portfolio discovery and routing |
| Campaign content | Time-bound commercial communication when approved |

## Planning rules

Build the slot map from the current merchant interface and frontend reference. Record uncertain or unavailable areas as `UNKNOWN` rather than forcing an Amazon or DTC structure.

Separate evergreen product content from volatile campaign, price, coupon and inventory content.

For long-image or text-heavy merchant content, define mobile reading order and information-density constraints before Production.

## Planning outputs

Record page target, editable areas/ownership, current builder/template constraints, Primary Reference, Channel Frontend Reference Pack, evergreen versus campaign split, mobile implications, page architecture and Complete Demo-Required Production Set.
