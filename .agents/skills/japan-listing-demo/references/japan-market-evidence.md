# Japan market evidence framework

## Principle

`JP` identifies the target country. It does not prove a consumer need, preference, scene, keyword, visual convention, or message priority.

Market conclusions must be supported by current evidence that is specific to the project category, channel, audience, and offer.

## Market Evidence Registry

Record each reusable or project-specific conclusion with the following fields:

| Field | Required content |
|---|---|
| source | Authoritative document, research, VOC set, channel capture, analytics, or current project decision |
| date | Publication, collection, capture, or approval date |
| market | `JP` and any narrower scope actually supported |
| locale | Requested consumer-copy locale |
| category | Current project category; never inferred from country |
| channel | Current sales or communication channel |
| evidence type | Product fact, VOC, search evidence, behavioral data, competitor evidence, expert review, or hypothesis |
| finding | The supported conclusion in neutral language |
| confidence | High, medium, low, or unverified |
| allowed usage | Strategy, copy, keyword research, visual brief, claim, comparison, or internal review only |
| expiry / refresh trigger | Date or condition requiring revalidation |

## Research sequence

1. Confirm the Project Definition.
2. Collect project documents, VOC, analytics, search evidence, current competitor pages, and channel constraints.
3. Separate direct evidence from interpretation.
4. Record conflicting findings instead of averaging them into one claim.
5. Assign confidence and allowed usage.
6. Use only evidence that matches the current category, channel, audience, and offer.
7. Revalidate volatile facts before formal release.

## What may be added

Evidence may support:

- consumer language;
- need states and purchase barriers;
- channel-specific information expectations;
- search-query families;
- usage contexts;
- visual environment and casting direction;
- proof requirements;
- message priority.

None of these may be preloaded as fixed national traits.

## Search and keyword research

Keyword work is generated from:

```text
current category
× current channel
× requested locale
× project evidence
× current search data
```

Do not maintain a country-wide keyword list and reuse it across unrelated products. Record query source, date, match type, intent, and allowed usage.

## Competitor evidence

A competitor page can support observations about:

- the competitor's message sequence;
- visible channel slots;
- copy language;
- proof objects;
- offer structure;
- current execution patterns.

It cannot prove:

- the current account's permissions;
- a product fact for the current project;
- a general market preference;
- a reusable category conclusion without corroborating evidence.

## Visual localization

Visual direction must be supported by the current audience, use context, category, offer, and channel. Proposed environments, people, objects, and interactions remain provisional until the project evidence or human review confirms them.
