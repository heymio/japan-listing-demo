# Installation decision pattern

## When to use
Use when compatibility, installation conditions, placement, or setup requirements materially affect purchase eligibility.

## Shopper question
Can I install or use this in my environment?

## Good composition
Organize the few conditions that determine eligibility, then show a clear yes/no/needs-check path without simulating unsupported installation details.

## Proof object
Confirmed dimensions, connection requirements, placement constraints, supported environment conditions, or approved installation diagrams.

## Information density
Medium. Prioritize decision gates over full manual content.

## Common failure
Copying installation rules from another product, implying universal compatibility, or turning the visual into a dense instruction manual.
