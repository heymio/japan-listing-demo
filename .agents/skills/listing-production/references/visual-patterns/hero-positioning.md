# Hero positioning pattern

## When to use
Use for the first high-level visual that must establish the product's overall purchase reason quickly.

## Shopper question
Why should I care about this product at all?

## Good composition
Product-first hero treatment, restrained context, one dominant promise, and enough negative space for clear hierarchy.

## Proof object
The product itself plus one direct contextual cue or evidence object that supports the positioning.

## Information density
Low. One primary message and only essential support.

## Common failure
Turning the hero into a feature collage, workflow map, or decorative lifestyle image with no clear purchase reason.
