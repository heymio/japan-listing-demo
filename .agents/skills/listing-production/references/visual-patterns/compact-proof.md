# Compact proof pattern

## When to use
Use when compactness, fit, reach, or space efficiency is itself a purchase reason.

## Shopper question
Will this actually fit or move through the kind of space I care about?

## Good composition
Show the product in a controlled spatial relationship with furniture, storage, clearance, or path width so the relationship itself communicates compactness.

## Proof object
A visible clearance, gap, footprint, or before/after spatial comparison supported by confirmed dimensions when needed.

## Information density
Low to medium. One spatial proof should dominate.

## Common failure
Using a huge empty room or a numeric “compact” label without a meaningful spatial relationship.
