# Mechanism explainer pattern

## When to use
Use when the shopper needs to understand how a mechanism creates the claimed benefit.

## Shopper question
How does this feature actually work?

## Good composition
Show one mechanism/action sequence with a clear beginning, action, and outcome; keep the real product geometry authoritative.

## Proof object
A visible mechanism, material flow, component relationship, or measured/confirmed action tied to the message.

## Information density
Medium. Prefer a short action → evidence → benefit chain over many labels.

## Common failure
Abstract technology effects, invented internals, or dense technical diagrams that do not explain the shopper benefit.
