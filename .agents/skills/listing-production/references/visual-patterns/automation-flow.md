# Automation flow pattern

## When to use
Use when the purchase value comes from a sequence of automated actions or reduced manual work.

## Shopper question
What happens automatically, and what still requires me?

## Good composition
Show a short, ordered cycle with clear ownership of each action and one consumer-value takeaway.

## Proof object
Confirmed stages in the automated flow, represented by real product states, UI evidence, or simple action icons tied to source facts.

## Information density
Medium. Limit the flow to the steps needed for the shopper decision.

## Common failure
Turning every supported function into a dense process chart, or implying automation for steps that still require manual action.
