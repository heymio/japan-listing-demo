# Comparison pattern

## When to use
Use when the shopper must choose between offers, modes, configurations, or evidence-backed product differences.

## Shopper question
Which option is right for me, and why?

## Good composition
Use aligned criteria, matched visual scale, and only decision-relevant differences. Keep unlike categories out of the same comparison.

## Proof object
Confirmed specification, offer content, workflow difference, or capability boundary for each compared option.

## Information density
Medium. Prefer a small number of high-decision-value rows or visual contrasts.

## Common failure
Overloaded spec tables, unsupported superiority claims, or comparisons that mix different scopes and imply a false winner.
